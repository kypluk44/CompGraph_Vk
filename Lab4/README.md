# Лабораторная 4 — карты теней

Вариант 11. Сцена Lab3 с двумя икосаэдрами, текстурами и освещением Блинн–Фонга дополнена полом.

## Запуск на macOS

Нужны CMake, Ninja, Xcode Command Line Tools и Vulkan SDK с MoltenVK и glslc. Устройство должно поддерживать Vulkan 1.3 и функцию dynamicRendering.

```bash
cd Lab4
source "$HOME/VulkanSDK/1.4.357.1/setup-env.sh"
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-lab4
```

При первой конфигурации CMake скачивает зависимости. После переноса папки повторите конфигурацию, чтобы обновить пути к текстурам и шейдерам.

## Что сделано по ТЗ

- Перед основным проходом геометрия рисуется в две depth-текстуры D32_SFLOAT 2048×2048 через vkCmdBeginRendering / vkCmdEndRendering. Один конвейер с шейдером shadow.vert используется для обеих карт.
- Для солнца используются LookAt и ортографическая проекция. Для первого прожектора в списке используются LookAt и перспективная проекция с углом обзора, равным удвоенному внешнему полууглу конуса.
- В основном фрагментном шейдере обе карты читаются через sampler2DShadow. Сэмплер сравнивает глубину фрагмента с записанной глубиной оператором LESS. Результат умножается на вклад соответствующего источника.
- Sun ortho half-size задаёт половину стороны области карты солнца. Depth bias меняет сдвиг глубины при построении обеих карт.

Чтобы показать только тень солнца, установите интенсивность прожектора в 0. Чтобы показать только тень прожектора, обнулите Directional intensity. Первый прожектор в списке отбрасывает тень. После удаления первого эту роль получает следующий.
