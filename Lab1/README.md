# Лабораторная работа 1 — вариант 11

Правильный икосаэдр на C++20, Vulkan, GLFW и ImGui. Реализован минимальный набор всех шести дополнительных заданий на оценку 5.

## Запуск на macOS

Из корня клонированного репозитория выполните команды ниже. Если SDK установлен в другой версии или папке, скорректируйте путь к `setup-env.sh`.

Установлены LunarG Vulkan SDK 1.4.357.1, CMake, Ninja и Xcode Command Line Tools.
Vulkan на Mac работает через MoltenVK. Сборка и отрисовка проверены на Apple M4 Pro, macOS 26.6.2.

```bash
cd Lab1
source "$HOME/VulkanSDK/1.4.357.1/setup-env.sh"
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

При первом конфигурировании CMake скачивает GLFW, vk-bootstrap, VMA, ImGui и GLM.
`glslc` должен быть в PATH. Шейдеры автоматически компилируются в `build-debug/shaders`.
Путь к ним записывается при сборке; после переноса проекта в другую папку нужно повторить конфигурирование и сборку.

## Управление и требования на 5

| Дополнительное задание | Элемент интерфейса или реализация |
| --- | --- |
| 1. Перспективная и ортографическая проекции | `Orthographic projection`; выключено — перспектива |
| 2. Положение, поворот, растяжение | `Position`, `Rotation` в градусах, `Scale` отдельно по X/Y/Z |
| 3. Пространственная траектория и вращение | `Play animation`, `Speed`, `Radius`, `Height` |
| 4. Изменение цвета | `Color` для выбранной фигуры |
| 5. Процедурные цвета вершин | RGB-палитра по индексу вершины, умноженная в шейдере на `Color` |
| 6. Несколько объектов и наборов дескрипторов | Два икосаэдра, отдельный `VkDescriptorSet` с матрицей и цветом каждого |

`Object` выбирает фигуру для редактирования. Положение и поворот задают базовое преобразование;
анимация добавляет к нему перемещение и вращение. Пауза фиксирует фазу движения.

## Код

- `source/application.cpp`: геометрия, буферы, дескрипторы, конвейер, матрицы, анимация, ImGui и команды отрисовки.
- `shaders/icosahedron.vert`: преобразование вершин и умножение цветов.
- `shaders/icosahedron.frag`: вывод интерполированного цвета.
- `source/graphics_internal.cpp`: инициализация Vulkan, буфер глубины и представление кадров.

Икосаэдр состоит из 12 вершин, 20 треугольников и 60 индексов. Вершинный и индексный буферы общие для обеих фигур.
Матрицы камеры находятся в общем наборе дескрипторов, матрица модели и цвет — в отдельном наборе каждой фигуры.
Матрицы вычисляются с GLM; для Vulkan используются глубина 0–1 и инверсия Y в проекции.

На MoltenVK формат глубины выбирается из поддерживаемых: `D24_UNORM_S8_UINT` или `D32_SFLOAT_S8_UINT`.
