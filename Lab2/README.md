# Лабораторная работа 2 — камера и освещение

Вариант 11 — правильный икосаэдр. C++20, Vulkan, GLFW, ImGui и GLM.
Реализованы базовое задание и все четыре дополнительных пункта для оценки 5.

## Запуск на macOS

Из корня клонированного репозитория:

```bash
cd Lab2
source "$HOME/VulkanSDK/1.4.357.1/setup-env.sh"
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-lab2
```

Нужны Vulkan SDK (с MoltenVK и glslc), CMake, Ninja и Xcode Command Line Tools.
При другой версии SDK измените путь к setup-env.sh. При первом конфигурировании
CMake скачивает зависимости с GitHub. Все четыре шейдера компилируются автоматически.
После переноса папки повторите конфигурирование и сборку: путь к SPIR-V задаётся при сборке.

## Условие и реализация

| Пункт | Реализация |
| --- | --- |
| Базовое задание | Один икосаэдр, камера, ambient и направленный свет; Блинн–Фонг во фрагментном шейдере |
| Нормали | Нормализованное векторное произведение рёбер каждой грани; отдельные вершины для плоских граней |
| 1. Наборы сцены и модели | set 0: UBO сцены + SSBO точечных источников + SSBO прожекторов; set 1: UBO преобразования и материала |
| 2. Точечный свет | Добавление, удаление, положение, цвет, интенсивность; затухание 1/r² |
| 3. Прожекторный свет | Добавление, удаление, положение, направление, цвет, интенсивность, внутренний и внешний полууглы; затухание 1/r² и мягкая граница |
| 4. Визуализация | Цветные кубы обоих типов источников и белый проволочный конус прожектора; отдельные шейдеры без освещения, общее скрытие/показ |

## Управление

Все настройки доступны в окне ImGui. Нажмите на заголовок раздела или источника,
чтобы раскрыть его параметры. Добавление доступно кнопками Add point light и
Add spot light; удаление — внутри раскрытого источника.

- Camera: положение, три угла поворота в градусах, угол обзора, ближняя и дальняя плоскости.
- Model and material: преобразование объекта, альбедо, цвет блика, показатель степени Shininess.
- Ambient and directional: цвет и интенсивность фонового света, направление, цвет и интенсивность направленного источника.
- Point lights / Spot lights: динамические списки источников с редактированием всех параметров.
- Show light cubes and spot cones: управляет только визуализацией источников; их вклад в освещение сохраняется.

Углы прожектора задаются от оси до границы конуса (полууглы). Внешний полуугол
не меньше внутреннего. При равенстве край резкий; при различии используется smoothstep.
Нулевое направление трактуется как направление вдоль -Z. Для затухания расстояние
снизу ограничено малым положительным значением, чтобы избежать деления на ноль.

## Устройство

- `source/application.cpp`: геометрия, вычисление нормалей, буферы, дескрипторы, конвейеры, UI, камера и команды рисования.
- `shaders/lighting.vert`: мировые координаты и преобразование нормалей обратной транспонированной матрицей.
- `shaders/lighting.frag`: ambient, направленный, точечный и прожекторный Блинн–Фонг.
- `shaders/unlit.vert` и `unlit.frag`: постоянный цвет кубов и конусов источников.
- `source/graphics_internal.cpp`: стартовая настройка Vulkan, swapchain, глубина, синхронизация и ImGui.

Икосаэдр имеет 12 уникальных позиций и 20 граней. Для нормалей плоских граней
вершины дублируются: вершинный буфер содержит 60 записей и 60 индексов.
Вершины/нормали передаются как атрибуты; освещение вычисляется в мировых координатах.

SSBO используют массивы без фиксированной длины в GLSL. При добавлении источников
буфер увеличивается по необходимости. При удалении меняется фактическое количество;
даже для пустого списка остаётся валидный минимальный буфер. Данные обновляются
после ожидания fence предыдущего кадра.
