# Лабораторная 3 — текстурирование

Вариант 11: два икосаэдра, камера и освещение из Lab2.
Реализованы база и дополнительные пункты 1–3. В условии оценивание противоречиво:
для 4 указаны первые три пункта, а пункт 3 отдельно помечен на 5.
По согласованию включён и компактный пункт 3 (specular/emissive).

## Запуск

Из корня клонированного репозитория:

```bash
cd Lab3
source "$HOME/VulkanSDK/1.4.357.1/setup-env.sh"
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-lab3
```

Нужны CMake, Ninja, Xcode Command Line Tools и Vulkan SDK с glslc/MoltenVK.
Исходники зависимостей CMake скачивает при первой сборке. После переноса папки
нужно повторить конфигурирование: пути к текстурам и SPIR-V заданы при сборке.

## Соответствие условию

- Изображения PNG загружаются с диска через включённую библиотеку stb_image.
- Атрибут UV генерируется процедурно для каждой треугольной грани.
- Текстуры загружаются staging-буфером в device-local VkImage с переходами layouts.
- Все вершинные/индексные буферы, включая маркеры, загружаются staging-копированием
  в память с DEVICE_LOCAL_BIT. На Apple Silicon физическая память общая с CPU,
  но ресурсы создаются как GPU/device-local и не отображаются приложением.
- Для свойств всех объектов и маркеров используется один dynamic UBO.
  Шаг структуры округлён по minUniformBufferOffsetAlignment. Dynamic offset передаётся
  в vkCmdBindDescriptorSets. Свойства объектов не передаются push-константами.
- Для каждого материала свой descriptor set: dynamic UBO + albedo/specular/emissive.
  Объекты с одинаковым материалом используют один и тот же набор с разными смещениями.
- Object выбирает модель; Texture задаёт её материал независимо от другой модели.
- Animated sampling включает смешивание двух выборок одного изображения с разными
  UV, сдвиги и модуляцию RGB от времени. Флаг и время передаются push constants.
- Карта specular умножает цвет блика; emissive добавляется после расчёта Блинн-Фонга.
  У материала Bricks отсутствующие карты заменены общей чёрной текстурой 1×1.

Текстуры авторские, процедурно подготовленные PNG в textures/. Tiles имеет карты
блика и зелёного свечения; Bricks использует чёрные заглушки. Полууглы прожектора,
управление камерой и источниками работают так же, как в Lab2. Show light cubes
управляет только отображением маркеров. Чтобы увидеть emissive в темноте, установите
ambient/directional intensity в 0 и удалите точечные/прожекторные источники.
